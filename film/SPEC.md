# SPEC — 종이 한 장 (스토리라인 B)

GOAL:    10월 아침의 정적이 종이 네 장을 뚫고 찢어지며 깨어난다. 끝에서 시청자는 "조용함이 찢어졌다"는 감각과 마지막 한 줄을 기억한다.
OUTPUT:  HyperFrames, 1920 x 1080, 30 fps
TIME:    30.0 s x 30 = 900 frames. 128 BPM, 14.0625 frames/beat, 1 bar = 1.875 s. 16 bars.
         beat b → t = b x 0.46875 s (프레임은 round(t x 30), 누적 금지)

LOOK:    매체 = 종이와 잉크. 레이어마다 실제 종이 한 종, 서체 한 종, 잉크 한 색.

         accent 형광 오렌지는 L3 부제 밑줄 하나에서 처음 등장하고, L4에서 전면화.
         찢김 단면(종이 속살) 폭 8-18 px, 레이어별 단면색: 한지 #FAF8F2, 크라프트 #E3CFA8, 신문 #F2EFE8.
         찢긴 구멍 아래로 그림자 0 10px 26px rgba(0,0,0,.32).
         비네트 6% (L1-L3만). 글로우·파티클·그라데이션 없음.

OBJECTS: 종이 4장 (섬유가 보이는 한지, 반점 있는 크라프트, 활자 단이 깔린 신문지, 평평한 형광 포스터),
         각 장의 찢긴 단면(흰 속살 + 섬유 지터), 붓·펜으로 쓰이는 글자, 신문 헤드라인 활자.

MOTION:  카메라 = 레이어 안의 종이 전체. 푸시인은 로그 스케일(지각 속도 일정), 접근은 power3.in, 찢김 직후 도착은 expo.out.
         찢김 반경: 저항 구간(0.30 s 동안 20%) → 터짐(power3.out). 구멍 중심 = 직전 글자의 ㅇ 속.
         붓 획: 글자별 좌→우 clip 와이프 0.34 s, 글자 간 0.18 s.  펜: 0.18 s, 0.12 s. (스코어의 붓·펜 소리와 같은 시각)
         ㅇ 조준점 P와 속 지름 COUNTER는 실제 DOM 레이아웃 위에서 측정·조준한 값이다. 글자 크기·위치를 바꾸면 다시 맞춘다.
         활자 착지: scale 1.35→1, 0.20 s expo.out, 착지 후 완전 정지.
         포스터: 박마다 하드 컷, 색면 교체는 반 마디마다.
