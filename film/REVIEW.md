# REVIEW — 종이 한 장

## 만든 것
- 스토리라인 B "종이 한 장"(끝없는 줌 + 찢김). A "알람이 아침을 찢는다", C "07:00:00"은 만들지 않았다(STORYLINES.md).
- 한지(붓) → 크라프트(펜) → 신문지(활자) → 형광 포스터(Pretendard Black). 전환은 오직 하나, 앞 글자의 ㅇ 속에서 종이가 방사형으로 찢기는 것.
- 마지막 줄은 변수 `closing`(s4-poster), 기본값 "시월, 다시 깨어나다"는 **임시 문구**다. 용도·브랜드 메시지가 정해지지 않았다.

## 측정한 것
- `hyperframes check`: 에러 0. 경고 1개는 남김(아래).
- 렌더: 30.0 s, 1920x1080, 30 fps, H.264 + AAC 48 kHz, 14.2 MB. 통합 라우드니스 -14.6 LUFS, 피크 -1.2 dBFS, LRA 3.5 LU.
- 마디별 RMS: 한지 -20 dB → 크라프트 -17.5 → 드럼 -16 → 드롭 -14(가장 크고 밝음, centroid 1.8 kHz) → 마지막 줄 -15.6 → 코다 -24.
- `hyperframes audio`: music으로 분류, 피크 20.41 s(드롭).
- ㅇ 조준점 3곳은 실제 DOM 레이아웃 위에서 측정·조준했고, 찢김 구간을 프레임 단위로 스냅샷해 구멍이 ㅇ 속에서 열리는지 확인했다.

## 확인하지 못한 것
- **음악은 측정만 했고 아무도 듣지 않았다.** 코드로 합성한 스코어라 상업 트랙 수준의 질감은 아니다. HeyGen에 로그인하면(`npx hyperframes auth login`) 카탈로그 곡으로 `assets/audio/score.wav`만 바꿔 끼울 수 있다. 큐 시각은 9.375 / 15.0 / 20.625 / 26.25 s.
- 폰 화면(360 px)에서의 판독은 시트로만 봤다. 신문 본문 단은 장식이라 판독 대상이 아니다.

## 가장 약한 샷
- 9.5–9.8 s: 첫 찢김 뒤 크라프트가 0.35 s 동안 비어 있다("그"가 9.84 s에 써짐). 시간이 있으면 "그"를 한 박 당기겠다.
- 마지막 줄 화면(26.25–30 s)은 문장 한 줄뿐이라 다른 샷에 비해 밋밋하다. 실제 브랜드 메시지·로고가 오면 그에 맞춰 엔드카드를 다시 짜야 한다.

## 의도적으로 둔 경고
- `timeline_track_too_dense`(s4-poster 트랙 1에 7개): 박마다 바뀌는 단어 시퀀스가 하나의 흐름이라 한 파일에 두었다.
- `canvas_overflow` 등 info: 푸시인 중 글자가 프레임 밖으로 커지는 것은 의도다.
